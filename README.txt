ĐẾM NGÀY+ — PHIÊN BẢN CÀI VÀO MÀN HÌNH CHÍNH IPHONE

TÍNH NĂNG:
- Tự lấy ngày hiện tại theo múi giờ của iPhone.
- Chọn ngày đích, tính còn bao nhiêu ngày hoặc đã qua bao nhiêu ngày.
- Chọn ngày bắt đầu và cộng/trừ số ngày (ví dụ 10/09/2026 + 45 = 25/10/2026).
- Tính theo ngày lịch, không bị sai vì giờ mùa hè.
- Hiển thị tiếng Việt và hoạt động ngoại tuyến sau lần tải đầu nếu được host HTTPS.

CHẠY TRÊN MÁY TÍNH:
- Mở file index.html bằng Chrome hoặc Edge để thử.

CÀI LÊN IPHONE (sau khi đăng website lên một máy chủ HTTPS):
1. Tạo repository trên GitHub.
2. Upload các file trong thư mục này (giữ nguyên thư mục icons) vào nhánh main.
3. Mở Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
4. Mở liên kết GitHub Pages của website trên iPhone bằng Safari.
5. Nhấn Chia sẻ -> Thêm vào Màn hình chính -> bật Mở dưới dạng ứng dụng web (nếu hiện) -> Thêm.

LƯU Ý:
- Đây là ứng dụng web PWA, không phải file IPA hay app được phát hành qua App Store.
- Chưa có URL trực tuyến vì cần đưa mã nguồn lên dịch vụ hosting.
- GitHub Pages tạo ra trang web công khai; không đưa thông tin cá nhân vào mã nguồn.
- Khi thử trực tiếp bằng file://, service worker không hoạt động; không ảnh hưởng chức năng tính ngày.
